# small-office-scene

This project was exported from [PlayCanvas](https://playcanvas.com), a web-first game engine and collaborative visual editor for building interactive 3D applications, games, and experiences.

This NPM + Vite export is designed for local development. Edit the project files, run the app with Vite, and create a production build when ready.

## Local Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Project Structure

- `src/main.mjs` bootstraps the PlayCanvas application.
- `src/bootstrap/` contains the generated startup code.
- `src/scripts/` contains editable project script assets when present.
- `src/data/` contains generated app config and scene data.
- `public/` contains runtime assets and static files.
